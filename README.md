# Recall PDF

Ask questions about a PDF and get answers only from that PDF, with page citations.
A retrieval-augmented generation (RAG) app built step by step with LangChain and
free local models through Ollama.

## Setup

```bash
git clone https://github.com/Sujal045/recall-pdf.git
cd recall-pdf
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt        # add -r requirements-dev.txt to regenerate samples
```

## Step 1: load the PDF

```bash
python step1_load.py samples/honeybees.pdf
python step1_load.py samples/scanned_page.pdf   # image-only page: no text, needs OCR
```

`rag/loader.py` turns a PDF into one LangChain `Document` per page.

## Step 2: split into chunks

```bash
python step2_split.py samples/honeybees.pdf                                       # 1000 / 150 (default)
python step2_split.py samples/honeybees.pdf --chunk-size 300 --chunk-overlap 100  # see the cuts
```

`rag/splitter.py` splits pages into overlapping chunks with `RecursiveCharacterTextSplitter`.
Each chunk keeps its page's metadata and adds `start_index`.

## Layout

- `rag/`: the reusable pipeline code, one module per step (`loader.py`, `splitter.py`).
- `stepN_*.py`: small scripts that run one step and print what it produced.
- `samples/`: sample PDFs, generated by `scripts/make_sample_pdfs.py`.
- `.vscode/` (local, gitignored): debug configs, one per step script.
