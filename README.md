# Recall PDF

Ask questions about a PDF and get answers only from that PDF, with page citations.
A retrieval-augmented generation (RAG) app built step by step with LangChain and
free local models through Ollama.

## Setup

```bash
git clone https://github.com/Sujal045/recall-pdf.git
cd recall-pdf
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt        # add -r requirements-dev.txt to regenerate samples
```

## Step 1: load the PDF

```bash
python step1_load.py samples/honeybees.pdf
python step1_load.py samples/scanned_page.pdf   # image-only page: no text, needs OCR
```

`rag/loader.py` turns a PDF into one LangChain `Document` per page.

## Step 2: split into chunks

```bash
python step2_split.py samples/honeybees.pdf                                       # 1000 / 150 (default)
python step2_split.py samples/honeybees.pdf --chunk-size 300 --chunk-overlap 100  # see the cuts
```

`rag/splitter.py` splits pages into overlapping chunks with `RecursiveCharacterTextSplitter`.
Each chunk keeps its page's metadata and adds `start_index`.

## Step 3: create embeddings

Needs [Ollama](https://ollama.com) running with the embedding model pulled:
`ollama pull nomic-embed-text`.

```bash
python step3_embed.py samples/honeybees.pdf
python step3_embed.py samples/honeybees.pdf --question "Who decoded the waggle dance?"
```

`rag/embeddings.py` turns text into 768-number vectors with `nomic-embed-text`, adding the
model's `search_document:` / `search_query:` prefixes, and compares them with cosine similarity.

## Step 4: store the vectors

```bash
python step4_store.py samples/honeybees.pdf          # embeds and saves to chroma_db/
python step4_store.py samples/honeybees.pdf          # again: reuses the saved vectors
python step4_store.py samples/honeybees.pdf --reset  # delete everything and re-embed
```

`rag/vectorstore.py` keeps all PDFs in one Chroma collection in `chroma_db/` (git-ignored),
using cosine distance. Each chunk gets a stable id and a `pdf_id` (hash of the file), so
re-indexing never duplicates chunks and a search can be limited to one PDF. The collection
records the embedding model and prefixes; opening it with different settings stops with an error.

## Step 5: retrieve

```bash
python step5_retrieve.py samples/honeybees.pdf
python step5_retrieve.py samples/honeybees.pdf --question "What do drones do?"
```

`rag/retriever.py` wraps the store in a retriever (`store.as_retriever`) limited to one PDF,
returning the top `k=4` chunks for a question. The script compares k=1 and k=4, similarity
and MMR search, and a fixed score threshold. It indexes with 300-character chunks by default
because the sample PDF's pages are short.

## Layout

- `rag/`: the reusable pipeline code, one module per step (`loader.py`, `splitter.py`, `embeddings.py`, `vectorstore.py`, `retriever.py`).
- `stepN_*.py`: small scripts that run one step and print what it produced.
- `samples/`: sample PDFs, generated by `scripts/make_sample_pdfs.py`.
- `.vscode/` (local, gitignored): debug configs, one per step script.
